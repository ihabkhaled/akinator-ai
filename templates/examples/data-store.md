# Data store - postgres (primary)

> Filled example of `templates/data-store.md`, written for the fictional Nimbus
> product described in `templates/examples/README.md`. Paths here are
> illustrative and do not exist in this repository.

- **Kind:** relational
- **Owner:** Ihab (owner)

## Purpose

The system of record for workspaces, seats, plans, billing state and export
jobs. Everything else in Nimbus can be rebuilt from it; it cannot be rebuilt
from anything.

## Schema home

`src/db/migrations/`. The table map in `context/data-model.md` is regenerated by
`scripts/extract_schema.py`.

## Migrations

Run by the `api` container on boot, before it accepts traffic. Additive only in
one release; a column is dropped at least one release after the last code stops
using it. Procedure with its point of no return: `docs/ops/schema-migration.md`.

## Retention

- Active workspace data: for the life of the workspace.
- Deleted workspaces: kept 30 days, then purged by the nightly job. The 30 days
  is the support promise on the pricing page.
- Billing records: 7 years, for tax.

## Backup and restore

- **Backup:** nightly snapshot kept 14 days, plus continuous log shipping
- **Last restore tested:** 2026-07-11, to a scratch instance
- **Restore time, measured:** _Unknown - ask the owner and record the answer._
  The July test restored the data but nobody timed it.

## Failure modes

| Failure | What users see | First response |
|---|---|---|
| Database unavailable | `api` returns 503; the worker pauses | `docs/ops/postgres-down.md` |
| Disk above 85 percent | Nothing yet; writes fail at 100 | Expand volume; check export job rows |
| Replica lag over 60 s | Billing page shows stale plan for a minute | Reads fall back to primary |

## Who reads and writes

- Writes: `api`, `worker`, `exports`
- Reads: the same three, plus a read-only role used by support tooling

## Cost

About 190 dollars per month for the primary and replica. The tier changes at
roughly 400 GB, which at current growth is not before 2027.

# Context

Structural facts about this repository, as machine-checkable maps. Facts, not
narrative - the reasoning lives in `docs/`.

Generated beats written: where a fact can be extracted from the tree, it is, and
an extractor keeps it true. See `skills/akinator-contextify/SKILL.md`.

| Map | Holds | Generated by |
|---|---|---|
| [Component map](components.md) - every skill, agent, command, hook, script and template, and which platform reads it | the plugin's own surface area | `scripts/extract_components.py` |

## Adding a map

Use `templates/context-map.md`. If the fact is extractable from the tree, write
the extractor rather than the map - one extractor removes an entire category of
future drift. A hand-written map must carry a review trigger and a last-verified
date, or the coverage check's `staleness` invariant fails it.
